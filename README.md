# OBSIDIAN: ЦВЕТОВАЯ СХЕМА ДЛЯ ЕЖЕДНЕВНЫХ ЗАМЕТОК

Данный репозиторий пердназначен для хранения стилей
и необходимых материалов для стилизации ежедневных заметок в Obsidian.

> [!TIP]
> По умолчанию в этой css-конфигурации используються шрифты Bai Jamjuree и JetBrainsMono Nerd Font Mono.
> Если вы не хотите их использовать, просто измените или удалите строки,
> относящиейся к семействам шрифтов в данной css-конфигурации.
